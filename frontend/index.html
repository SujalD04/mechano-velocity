The Challenge

Why Current Models Fail

RNA velocity models predict cell movement based on gene expression kinetics — but they ignore the physical tissue landscape.

❌

What scVelo Assumes

🔵
→ → →
Empty Space

"If a cell expresses migration genes, it must be moving."

  • Treats tissue as empty space
  • Only considers RNA splicing kinetics
  • Produces false-positive migration predictions
✅

Physical Reality

🔵
🧱🧱🧱
Collagen Wall

"Dense collagen walls physically block cell movement."

  • Tumors contain desmoplastic stroma (scar tissue)
  • Collagen fibers form impenetrable barriers
  • Velocity should be zero in walls
💡

Our Solution

Mechano-Velocity detects physical barriers using gene signatures, calculates a resistance field, and applies physics-based corrections to velocity predictions.

Notebook 01

Preprocessing

From raw 10x Visium data to a clean, normalized, clustered dataset.

1

Data Loading

Load the 10x Visium Breast Cancer dataset (H5 matrix + spatial coordinates) into an AnnData object via scanpy.

2

Quality Control

Filter spots by total UMI counts, genes detected, and mitochondrial %. Remove dead cells and empty spots.

3

Normalization

CPM normalization (scale to 10,000 counts per spot) + log1p transformation to compress dynamic range.

4

Feature Selection

Select ~2,000 Highly Variable Genes (HVGs) from ~36,000 total. These capture biological signal while reducing noise.

5

Dimensionality Reduction

PCA reduces 2,000 genes to ~50 principal components. Neighbor graph connects similar spots in expression space.

6

Clustering

Leiden algorithm groups spots into biologically meaningful clusters. UMAP provides 2D visualization.

The Physics Equations

Raw Density Score

Collagen builds the wall, LOX hardens it, MMP9 breaks it down.

Normalized Resistance

Sigmoid maps raw density to a probability [0, 1]. μ centers at the dataset mean.

α Collagen Weight 1.0
β LOX Multiplier 0.5
γ MMP Penalty 0.8
μ Sigmoid Center Auto (mean)

📊

Gene Expression Matrix

Sparse HDF5 matrix: ~3,800 spots × ~36,000 genes. Each value = UMI count (RNA molecules captured at that spot for that gene).

🔬

H&E Tissue Images

Microscopy photos of the stained tissue. Pink streaks = collagen (eosin). Purple dots = cell nuclei (hematoxylin). Used for validation.

📍

Spatial Coordinates

Each barcode maps to (x, y) pixel coordinates on the tissue image. scalefactors_json.json converts between resolution levels.

🎯

Scale Factors

Spot diameter: ~177px (55μm). Hires scale: 8.25%. Lowres scale: 2.48%. Fiducial diameter: ~287px (for alignment).
